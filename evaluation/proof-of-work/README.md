### To produce these artifacts

```bash
cp .env.example .env          # set EVAL_MODELS + credentials
# install OpenHands and make sure `openhands` is on PATH
npm run build
npm run generate
```

the exact OpenHands command, exit code, build status, measured score, per-test
results and failure categories, and the table below is regenerated from that data.
